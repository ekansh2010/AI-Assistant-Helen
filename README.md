# 🤖 Overview

Helen is a real-time AI voice assistant designed to combine natural human-like conversation with intelligent desktop automation. Inspired by futuristic assistants like Jarvis, Helen delivers seamless voice interaction, system-level control, conversational memory, and a cinematic AI experience.

The assistant can perform real-world tasks such as launching applications, controlling files and folders, automating keyboard and mouse actions, performing live web searches, and providing weather updates through natural voice commands.

# ⚙️ Installation Process

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/helen-ai.git
cd helen-ai
```

---

## 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

---

## 3️⃣ Activate Virtual Environment

### Windows

```bash
.\venv\Scripts\Activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Configure Environment Variables

Create a `.env` file in the root directory:

```env
GOOGLE_API_KEY=your_google_api_key
GOOGLE_SEARCH_API_KEY=your_google_search_api_key
SEARCH_ENGINE_ID=your_search_engine_id
OPENWEATHER_API_KEY=your_openweather_api_key
```

---

## 6️⃣ Run the AI Assistant

```bash
python agent.py
```

---

## 7️⃣ Run Frontend

```bash
pnpm install
pnpm dev
```
